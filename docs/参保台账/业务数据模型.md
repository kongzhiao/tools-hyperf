# 参保台账业务数据模型

金额使用 `decimal(14,2)`。配置表使用软删除；台账、快照、导入批次和复核表当前不使用软删除。

## enroll_configs

附件1/2身份配置。

| 字段 | 类型 | 空/默认 | 注释 | 索引 |
|---|---|---|---|---|
| `id` | bigint | 自增 | 主键 | PRIMARY |
| `year` | int | 非空 | 配置年份 | 三个组合索引首列 |
| `config_type` | varchar(30) | subsidy | subsidy/medical | `idx_year_config_type` |
| `priority` | int | 0 | 越小越优先 | `idx_year_type_priority` |
| `identity_name` | varchar(150) | 空串 | 身份名称 | `idx_year_type_identity` |
| `insurance_level` | varchar(80) | 可空 | 资助/参保档次 | 无 |
| `subsidy_standard` | varchar(120) | 可空 | 资助标准 | 无 |
| `personal_amount` | decimal(14,2) | 0 | 个人实缴 | 无 |
| `subsidy_amount` | decimal(14,2) | 0 | 资助代缴 | 无 |
| `included_identities` | json | 可空 | 包含身份数组 | 无 |
| `status` | tinyint | 1 | 1启用/0停用 | 无 |
| `remark` | varchar(500) | 可空 | 备注 | 无 |
| 时间戳+`deleted_at` | timestamp | 可空 | 软删除 | 无 |

无配置组合唯一约束。

## enroll_ledgers

年度人员主台账。

| 字段组 | 字段与类型 | 空/默认 | 索引/说明 |
|---|---|---|---|
| 主键 | `id bigint`, `year int`, `id_card varchar(32)` | 自增；year非空；身份证空串 | `idx_year_id_card`，非唯一 |
| 人员 | `name varchar(80)`, `town_name varchar(120)`, `village_name varchar(120)` | 可空 | year+town索引 |
| 周期变化 | `included_month varchar(20)`, `cancel_month varchar(20)`, `change_status varchar(30)` | 可空；change默认新增 | year+change索引 |
| 原始身份 | `raw_identity varchar(255)` | 可空 | 附件3原始身份 |
| 医疗身份 | `medical_identity_records json`, `medical_identity varchar(150)` | 可空 | year+medical_identity索引 |
| 资助身份 | `subsidy_identity_records json`, `subsidy_identity varchar(150)` | 可空 | year+subsidy_identity索引 |
| 缴费 | `resident_payment_amount decimal(14,2)`, `payment_time varchar(30)` | 0/NULL | 系统缴费金额和时间 |
| 税务 | `subsidy_amount decimal(14,2)`, `subsidy_identity_obtained varchar(150)`, `tax_request_batch varchar(80)`, `tax_first_request_amount decimal(14,2)` | 金额0；文本可空 | 附件5 |
| 参保结果 | `insurance_category varchar(120)`, `is_insured varchar(20)`, `uninsured_reason varchar(255)` | 可空 | year+is_insured索引 |
| 资助结果 | `is_eligible_for_subsidy varchar(20)`, `is_subsidy_obtained varchar(20)`, `subsidy_method varchar(80)` | 可空 | 计算结果 |
| 备注 | `insurance_place_remark varchar(255)`, `death_remark varchar(255)`, `manual_remark varchar(500)` | 可空 | 区外/死亡/人工 |
| 镇街填报 | `town_is_insured varchar(20)`, `town_uninsured_reason varchar(255)`, `town_resident_payment_amount decimal(14,2)`, `town_death_time varchar(30)`, `town_remark varchar(500)` | 可空 | 镇街输入 |
| 填报审计 | `town_submit_status varchar(30)`, `town_submitted_at datetime`, `town_last_filled_by bigint`, `town_last_filled_at datetime` | 未填报/NULL/0/NULL | year+submit状态索引 |
| 金额核查 | `payment_amount_check_status varchar(30)`, `payment_amount_check_remark varchar(255)` | 未填报/NULL | year+核查状态索引 |
| 复核 | `current_review_batch_id bigint`, `review_status varchar(30)` | 0/未下放 | current批次索引；year+review索引 |
| 最近来源 | `last_attachment3_period`,`last_attachment4_period`,`last_attachment5_period`,`last_attachment6_period`,`last_payment_time_period` varchar(20) | 可空 | year+附件3月份索引 |
| 审计 | `created_at`,`updated_at` timestamp | 可空 | 无软删除 |

状态值：

- `change_status`：新增、变更、取消；迁移将旧“正常”修正为“新增”。
- `review_status`：未下放、待填报、已填报、已收回。
- `town_submit_status`：未填报、已填报。
- `payment_amount_check_status`：未填报、一致、待核查、已核查。

## business_filter_options（参保使用）

参保使用 `module=enroll`。表结构：

| 字段 | 类型 | 空/默认 | 注释/索引 |
|---|---|---|---|
| `id` | bigint | 自增 | PRIMARY |
| `module` | varchar(100) | 空串 | 业务模块；组合索引首列 |
| `type` | varchar(100) | 空串 | 选项类型；组合索引第二列 |
| `value` | varchar(255) | 空串 | 选项值；`idx_module_type_value` |
| `label` | varchar(255) | 空串 | 显示名称 |
| `status` | tinyint | 1 | 1启用/0停用；`idx_module_type_status` |
| `sort` | int | 0 | 排序 |
| `source_batch` | varchar(50) | 可空 | 来源批次 |
| `remark` | varchar(255) | 可空 | 备注 |
| `created_at`,`updated_at`,`deleted_at` | timestamp | 可空 | 时间戳和软删除 |

当前类型至少包括：

- `uninsured_reason`：未参保原因，默认死亡、服刑、服役、拒参、失踪、无法联系、已注销户口、户口迁出、其他。
- 居民缴费金额对应页面配置类型，供镇街填报金额白名单。

字段和通用规则见该模型/迁移；参保服务读取启用项校验镇街提交值。

## 逻辑关联与约束

- review item → batch/ledger、created_by → users 均为逻辑关联，无外键。
- 台账年度身份证、配置组合由应用层保证，不是数据库唯一约束。
- JSON身份记录保留匹配结果快照；运行时当前身份取排序第一项。
