# 参保台账用户说明

完整面向用户的离线说明位于 `helps/参保台账用户操作与核对参考文档.html`（更新于2026-07-05）。

## 管理员操作顺序

1. 选择年度，维护附件1资助参保身份、附件2医疗救助身份、附件7身份对应明细。
2. 维护未参保原因和居民缴费金额。
3. 选择导入月份并上传附件3全量明细。
4. 在任务中心确认完成，在参保导入记录检查成功/失败和未匹配身份。
5. 导入附件4参保核实、附件5税务请款、附件6死亡名单。
6. 必要时导入附件3人工调整回导。
7. 按镇街、勾选记录或筛选条件下放复核。
8. 查看下放批次和镇街填报进度，必要时收回异常批次/记录。
9. 对缴费金额待核查记录核对凭证并标记已核查。
10. 导出汇总名单、对比结果或特殊对象资助参保台账。

附件3必须先于附件4/5/6。导入只支持 CSV，提交后必须核验异步任务。

## 镇街操作

- 只可查看本镇街已下放且未收回的待填报/已填报记录。
- 可填写是否参保、未参保原因、居民缴费金额、死亡时间和镇街备注。
- 是否参保为否时选择配置内未参保原因；为是时金额从年度配置选项中选择。
- 保存后系统重新计算，金额不一致时进入待核查。
- 数据被管理员收回后立即不再可见。

## 重点核对

- 附件3新增/变更/取消数量符合月度全量变化。
- 多身份人员取正确优先身份；9999表示配置未匹配。
- 附件4金额和区外备注正确。
- 附件5同身份证金额按行累加。
- 附件6死亡人员相关结果为否。
- 是否符合资助要同时检查月份、身份对应明细和缴费金额。
- 下放前确认筛选条件，收回前保留必要填报结果。

## 导出

- 汇总名单：当前筛选台账，动态生成资助身份列。
- 对比结果：当前筛选的新增/变更/取消。
- 特殊对象资助参保台账：完整最终台账字段。

镇街账号导出自动套用本镇街复核可见范围。
