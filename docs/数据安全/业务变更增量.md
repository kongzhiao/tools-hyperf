# 业务敏感数据加密变更增量

## 2026-08-23

- 新增：基于 OpenSSL 的 RSA + AES-256-GCM 混合加密，不引入第三方加密包。
- 新增：模型 `$encrypts` 透明加密写入和解密读取；空值与空字符串保持原样。
- 新增：姓名、身份证件号等完整值 HMAC 盲索引及精确查询作用域。
- 新增：12 张第一批业务表的字段扩容、明文索引替换和盲索引列。
- 修正：统计汇总模型统一使用实际表名 `statistics_summery`。
- 调整：相关导入、批量更新、查询、统计和导出路径改为模型加密写入或盲索引精确查询。
- 新增：`data:encrypt-sensitive` 老数据分批升级命令，支持演练、指定表、检查点续跑和处理后校验。
- 新增：老数据升级命令按批次同步输出终端进度并写入 `runtime/logs/sensitive-encryption.log`，记录运行编号、百分比、最后主键和耗时，不记录业务敏感值。
- 新增：生产密钥权限、自检、公私钥匹配和禁止密文直接回滚保护。
- 范围：仅处理已确认的第一批业务字段，不扩展到附件、临时文件和其他第二批数据。
