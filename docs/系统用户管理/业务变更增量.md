# 系统用户管理业务变更增量

## 2026-08-23

- 新增：登录成功、密码错误、账号锁定、TOTP 验证、TOTP 重置、解除锁定和退出操作审计。
- 调整：新密码统一为至少 8 位，且必须包含字母和特殊符号；不批量阻断存量密码。
- 新增：按用户名而非 IP 统计登录失败，15 分钟内失败 5 次后按 10、30、60 分钟阶梯锁定。
- 新增：超级管理员和精确名称“管理员”的角色可清除锁定。
- 新增：RFC 6238 TOTP 首次绑定、每次登录验证和过期会话恢复；非 `prod` 环境跳过验证码校验。
- 新增：用户安全设置入口；不提供恢复码、关闭或主动重新绑定，由具备管理能力的账号重置他人 TOTP。
- 调整：数据库 `totp_required` 默认关闭兼容老数据，新增页面默认开启；超级管理员和“管理员”角色始终强制开启。
- 保护：“管理员”角色不可改名、删除或重复创建。
- 调整：服务端会话改为 Redis 活动续期 24 小时，最多每 10 分钟刷新一次。
- 调整：登录和退出均能关联实际用户写入操作记录；登录密码只记录确认的脱敏形式。

## 2026-07-12

- 新增：建立系统用户管理后端文档基线。
- 确认：后台账号、JWT、RBAC 和镇街范围的既有实现。
- 确认：用户 `id=1` 为超级管理员。
- 已知限制：用户无启停与软删除；删除不可恢复。
