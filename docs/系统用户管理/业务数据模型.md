# 系统用户管理业务数据模型

## users

后台登录账号表。无软删除、无状态字段。

| 字段 | 类型 | 空/默认 | 边界与注释 | 索引 |
|---|---|---|---|---|
| `id` | bigint unsigned | 非空/自增 | 主键；`1`为超级管理员 | PRIMARY |
| `username` | varchar(64) | 非空 | 登录名，唯一 | UNIQUE `users_username_unique` |
| `password` | varchar(255) | 非空 | 单向密码哈希，不可回显 | 无 |
| `nickname` | varchar(255) | 可空/NULL | 显示昵称 | 无 |
| `town_id` | bigint unsigned | 可空/NULL | 所属镇街；空为全局账号 | `idx_users_town_id` |
| `created_at` | timestamp | 可空/NULL | 创建时间 | 无 |
| `updated_at` | timestamp | 可空/NULL | 更新时间 | 无 |

`town_id` 逻辑关联 `towns.id`，迁移只增加普通索引，没有外键。

## roles

| 字段 | 类型 | 空/默认 | 注释 | 索引 |
|---|---|---|---|---|
| `id` | bigint unsigned | 非空/自增 | 角色主键 | PRIMARY |
| `name` | varchar(64) | 非空 | 角色名 | UNIQUE `roles_name_unique` |
| `description` | varchar(255) | 可空 | 说明 | 无 |
| `created_at` | timestamp | 可空 | 创建时间 | 无 |
| `updated_at` | timestamp | 可空 | 更新时间 | 无 |

## permissions

| 字段 | 类型 | 空/默认 | 边界与注释 | 索引 |
|---|---|---|---|---|
| `id` | bigint unsigned | 非空/自增 | 权限主键 | PRIMARY |
| `name` | varchar(100) | 非空 | 稳定权限名 | UNIQUE `permissions_name_unique` |
| `description` | varchar(255) | 可空 | 权限说明 | 无 |
| `type` | enum(menu,operation) | 非空/operation | 菜单或操作 | `permissions_type_index` |
| `parent_id` | bigint unsigned | 非空/0 | 父权限ID；0为根 | `permissions_parent_id_index` |
| `path` | varchar(255) | 可空 | 前端路由 | 无 |
| `component` | varchar(255) | 可空 | 前端组件 | 无 |
| `icon` | varchar(50) | 可空 | 图标名 | 无 |
| `sort` | int | 非空/0 | 排序 | `permissions_sort_index` |
| `status` | tinyint | 非空/1 | 1启用、0停用 | `idx_permissions_status` |
| `created_at` | timestamp | 可空 | 创建时间 | 无 |
| `updated_at` | timestamp | 可空 | 更新时间 | 无 |

`parent_id` 为自关联逻辑键，没有数据库外键。

## role_user

用户与角色多对多关联，无时间戳。

| 字段 | 类型 | 空/默认 | 注释 | 索引/约束 |
|---|---|---|---|---|
| `user_id` | bigint unsigned | 非空 | 用户ID | 组合PRIMARY；FK users，级联删除 |
| `role_id` | bigint unsigned | 非空 | 角色ID | 组合PRIMARY；索引；FK roles，级联删除 |

组合主键保证同一用户角色不重复。

## role_permissions

| 字段 | 类型 | 空/默认 | 注释 | 索引/约束 |
|---|---|---|---|---|
| `id` | bigint unsigned | 非空/自增 | 主键 | PRIMARY |
| `role_id` | bigint unsigned | 非空 | 角色ID | 组合唯一的一部分 |
| `permission_id` | bigint unsigned | 非空 | 权限ID | UNIQUE `(role_id,permission_id)` |
| `created_at` | timestamp | 可空 | 创建时间 | 无 |
| `updated_at` | timestamp | 可空 | 更新时间 | 无 |

SQL快照中未声明 role_permissions 外键；模型通过 `belongsToMany` 逻辑关联。

## towns（用户关联部分）

| 字段 | 类型 | 空/默认 | 注释 | 索引 |
|---|---|---|---|---|
| `id` | bigint unsigned | 非空/自增 | 镇街主键 | PRIMARY |
| `name` | varchar(64) | 非空 | 镇街名称 | `idx_towns_name` |
| `code` | varchar(32) | 可空 | 镇街编码 | 无 |
| `status` | tinyint | 非空/1 | 1启用、0停用 | `idx_towns_status` |
| `sort` | int | 非空/0 | 排序 | 无 |
| `remark` | varchar(255) | 可空 | 备注 | 无 |
| `created_at`,`updated_at` | timestamp | 可空 | 时间戳 | 无 |
| `deleted_at` | timestamp | 可空 | 软删除 | 无 |

## Redis 用户缓存

- Key：`user:cache:{user_id}`。
- 值：序列化的 `toJwtArray()`，包括用户、镇街、权限和菜单。
- TTL：7200 秒。
- 用户编辑、删除、角色分配、本人改密和登出会尝试清除。

Redis 不是事实主库；未命中时回源 MySQL。
