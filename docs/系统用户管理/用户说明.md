# 系统用户管理用户说明

## 创建与配置账号

1. 创建账号时填写唯一用户名、昵称和初始密码。
2. 需要限制镇街范围时绑定所属镇街；不绑定即全局账号。
3. 创建后分配一个或多个角色。
4. 让使用人首次登录后通过右上角修改本人密码。

账号创建与角色分配是两个动作。没有角色的账号可能登录成功但缺少业务权限。

## 编辑

- 可改用户名、昵称、镇街和密码。
- 密码留空不更新；填写后立即用新密码替换。
- 改镇街会改变未救助通知和参保复核的可见数据范围。
- 改角色会完整替换原角色集合。

## 删除

当前没有禁用和回收站。删除会移除用户并由外键级联删除 `role_user` 关联。确认账号永久不再使用后再删除。

## 登录和修改密码

- 登录成功签发2小时 JWT，并把用户权限上下文缓存2小时。
- 修改本人密码必须提供正确原密码。
- 修改成功后清除 Redis 用户缓存，前端要求重新登录。
- 当前登出路由未经过 JWT 中间件，正常退出应以前端清理本地 Token 为准。

## 排查

- 用户列表看不到超级管理员：代码固定排除 `id=1`。
- 镇街账号无数据：检查 `users.town_id`、角色权限、数据是否已下放和业务周期。
- 权限更新未生效：确认角色关联和权限状态，重新登录刷新缓存。
- 无启停入口：当前表结构未实现状态字段，不应通过删除模拟临时禁用。
