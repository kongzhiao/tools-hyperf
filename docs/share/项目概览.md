# 项目概览

## 项目定位

`tools-hyperf-yf` 是共享救助信息服务平台后端，向管理端提供认证、RBAC、医保数据导入、匹配、筛查、统计、复核、任务和导出接口。配套前端是同级 `tools-react-yf`。

## 技术架构

- Hyperf 3 / Swoole 协程服务。
- MySQL 保存配置、台账、用户、权限和任务记录。
- Redis 用于用户信息缓存、异步队列和业务任务锁。
- JWT 提供后台登录认证，有效期当前为 2 小时。
- OpenSpout 流式读取 CSV，编码自动识别并转 UTF-8。
- 异步任务处理大文件导入、筛查和导出。

## 请求链路

```text
HTTP /api
  -> JwtAuthMiddleware
  -> Controller
  -> Service / Model
  -> MySQL / Redis

耗时操作：Controller -> TaskService -> Redis Async Queue -> Job -> Task/文件/业务表
```

## 重点业务模块

### 系统用户管理

后台账号通过 JWT 登录，角色与权限控制菜单和操作。`town_id` 决定全局或镇街数据范围。当前账号没有启停字段，删除为直接删除。

### 未救助台账

处理附件1未救助明细、附件2救助对象、附件4应补应退、通知明细和重大疾病编码。筛查只标记业务结果，不删除原始记录；通知流程独立记录下放、接收、通知、反馈和报销状态。

### 参保台账

按年度维护身份和金额配置，按月导入附件3/4/5/6，计算身份变化、参保类别和资助结果；支持镇街复核批次、填报、收回、缴费核查和三类导出。

## CSV 处理

- 当前台账接口只允许 `.csv`。
- 支持 UTF-8 BOM、UTF-8、GBK、GB18030，并去除 BOM/零宽字符。
- 使用流式读取避免一次性加载大文件。
- 表头支持业务中文名称和部分兼容别名，具体见各功能文档与 Job。
- 任务状态和文件下载对用户隔离，任务仅允许创建人查看和下载。

## 数据库迁移

Hyperf 当前默认扫描根 `migrations/`。`database/migrations/` 保存了大量同名存量文件，但不是默认执行来源，且个别历史文件并不完全一致。任何数据库事实必须以实际环境已执行迁移和根目录增量为准。

## 当前协议现状

多数普通业务接口成功返回 `code = 0`；任务中心接口当前返回 `code = 200`。提示字段同时存在 `msg` 和 `message`。这是存量协议事实，统一改造需独立任务，详见 [`接口规范.md`](接口规范.md)。
