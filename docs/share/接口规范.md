# 接口规范

## 基础路径与认证

业务接口位于 `/api`。除登录等公开路由外，使用 JWT：

```http
Authorization: Bearer <token>
```

JWT 当前包含 `user_id`、`username`、签发时间和两小时过期时间。中间件注入 `userId`、`user`、`username`。不得在 URL、响应、日志或文档输出 Token。

## 当前成功码

项目存在两套存量成功码：

| 接口范围 | 成功 `code` | 提示字段 |
|---|---:|---|
| 用户、未救助、参保等大多数业务接口 | `0` | `msg` 或 `message` |
| `/api/tasks`、`/api/tasks/count`、`/api/tasks/progress` | `200` | `message` |

普通业务典型响应：

```json
{
  "code": 0,
  "message": "获取成功",
  "data": {}
}
```

任务典型响应：

```json
{
  "code": 200,
  "message": "获取成功",
  "data": {}
}
```

不能套用其他项目的成功码。新增普通接口建议使用 `code = 0`、`msg`、`data`；全量统一需独立评估前端兼容。

## 错误语义

- `400`：参数或业务校验失败。
- `401`：Token 缺失、无效、过期或用户不存在。
- `403`：无权限或越过数据范围。
- `404`：资源或任务不存在。
- `500`：未预期系统异常。

错误不得包含 SQL、堆栈、内部路径、密钥或完整敏感信息。

## 分页

| 模块 | 请求 | 返回 |
|---|---|---|
| 用户 | `page`, `limit` | `list,total,page,limit` |
| 未救助/应补应退/通知 | `page`, `page_size`，部分兼容 `limit` | `list,total,page,page_size` |
| 参保 | `page`, `page_size` | `list,total,page,page_size` |
| 任务 | `page`, `page_size` | `list,total,page,page_size` |

页码最小为 1。新增列表必须限制最大页大小并使用稳定排序。

## 文件上传

- 使用 `multipart/form-data`。
- 文件字段为 `file`，只接受 `.csv`。
- 按接口携带 `settlement_period` 或 `year + period`。
- 服务端将文件移动到临时上传目录后投递异步任务。
- 重复同类业务任务可能因 Redis 锁返回业务错误。

提交响应返回任务 UUID，例如：

```json
{
  "code": 0,
  "message": "任务已提交",
  "data": { "uuid": "..." }
}
```

这只表示已入队，不表示导入、筛查或导出成功。

## 任务接口

- `GET /api/tasks`：本人任务分页。
- `GET /api/tasks/count`：本人未完成数量。
- `GET /api/tasks/progress?uuid=...`：本人单任务进度。
- `GET /api/download?uuid=...`：下载本人已完成文件。

任务状态：`pending`、`processing`、`completed`、`failed`、`cancelled`。任务列表不返回服务器真实文件路径，只返回 `has_file`。

## 镇街范围

- 用户 `town_id` 为空表示全局账号。
- 非空时，未救助通知按 `town_id`，参保复核按当前用户 `town_name`/绑定镇街强制过滤。
- 请求中的镇街筛选不能扩大当前用户范围。
- 镇街写操作还需校验记录处于允许的下放/填报状态。

## 接口索引

各功能的完整接口和参数见对应 `docs/<功能>/README.md`。路由最终以 `config/routes.php` 为准；控制器中存在但未注册路由的方法不属于公开接口。
