# 开发规范

## 总原则

- 先读文档和相邻实现，再修改。
- 业务说明、字段注释和变更记录使用简体中文。
- 代码、帮助页和文档冲突时以当前有效代码为准。
- 只修改需求必要范围，不恢复遗留资料，不覆盖用户改动。

## 分层

```text
Request -> Middleware -> Controller -> Service -> Model/DB/Redis
                                    -> TaskService -> Queue Job
```

- Controller：参数、当前用户、范围控制、服务调用和响应。
- Service：金额、身份、镇街匹配、筛选、规则和可复用业务编排。
- Model：表、关联、fillable/guarded、casts。
- Job：导入、筛查、导出等长任务；必须可报告进度和失败。
- Command：初始化、核对和运维命令，不应替代正式迁移。

## 路由与认证

- 路由事实统一维护在 `config/routes.php`。
- 除登录、健康检查、帮助页等明确公开接口外，业务路由使用 `JwtAuthMiddleware`。
- Token 优先从 Bearer Header 读取。新功能不得使用 query Token，现有兼容仅用于本地测试。
- 当前用户从请求属性读取，不重复解析 JWT。
- 路由、权限和前端按钮名称变更必须同步。

## 响应与异常

- 存量普通业务成功码为 `0`，任务接口为 `200`，详见接口规范。
- 新普通接口建议统一 `code`、`msg`、`data`，但不得在普通需求中顺手改旧接口。
- 可预期业务错误使用明确 400/401/403/404 语义。
- 未预期异常不得输出框架 HTML、SQL、堆栈和服务器路径；当前全局异常处理仍有改进空间，非本次文档任务不调整。

## 列表与查询

- 页码最小 1，分页字段按模块现有约定；新增接口应限制合理 `page_size` 上限。
- 排序字段必须使用白名单，不能把请求字段直接拼入 SQL。
- 大表查询优先组合索引字段，避免无清算期/年度限制扫描。
- 镇街账号必须由服务端强制追加镇街和业务状态范围。
- 列表选择必要字段，避免返回无关大 JSON 或敏感字段。

## 金额、日期和状态

- 金额使用 `decimal(14,2)`，读写和比较保持两位小数；禁止将浮点误差写入业务判断。
- 未救助清算期标准化为 `YYYYMM`；参保月份标准化为 `YYYY-MM`。
- 日期解析需兼容空值、`--`、零日期和常见中文/分隔格式。
- 状态使用服务常量，禁止散落新的同义字符串。
- 状态改变需校验允许来源状态，批量操作返回实际影响和跳过数量。

## CSV

- 控制器校验有效上传和 `.csv` 扩展名。
- `CsvReaderService` 负责编码、BOM、空行、表头和流式遍历。
- Job 通过 `pickValue()` 兼容明确表头别名；新增别名需有业务依据并更新文档。
- 导入匹配键必须明确：未救助通常为清算期+序号或身份证，参保为年份+身份证。
- 同批失败策略要说明是整批终止、跳过单行还是保留部分结果。
- 临时文件在 `finally` 中清理，文件名和路径不得直接返回调用方。

## 异步任务

- 使用 `TaskService::dispatchTask()` 创建记录、业务锁和队列 Job。
- 任务状态：`-2 failed`、`-1 cancelled`、`0 pending`、`1 running`、`2 completed`。
- 开始调用 `startTask()`，完成调用 `finishTask()` 或等价更新，失败调用 `failTask()`。
- 业务锁应绑定操作类型和业务周期，结束和失败均释放。
- `failure_reason` 面向用户，最长当前截断 1000 字；完整堆栈只记录日志。
- 导出通过任务 UUID 和下载中转，验证任务归属。

## 数据模型与迁移

- 新增迁移放根 `migrations/`，完整定义 up/down。
- 明确长度、精度、可空、默认、注释、索引、唯一性和软删除。
- 表和模型的时间戳/软删除策略必须一致。
- 不把普通索引描述为唯一约束；业务唯一键仅靠代码时要在文档标记风险。
- 不提交真实 SQL 数据快照、密码哈希或生产数据作为功能说明。

## 安全

- 密码只保存 `password_hash()` 结果，不回显、不提供查看。
- 身份证、电话、银行卡号和姓名属于敏感业务数据，日志只保留必要且脱敏的上下文。
- JWT 密钥、数据库/Redis口令、生产地址和 `.env` 不进入代码或文档。
- 错误信息不返回内部异常原文；下载、任务和镇街数据均校验归属。

## 验证

- 纯文档检查结构、链接、表格、Mermaid 和与代码事实的一致性。
- PHP 改动至少运行相关文件语法检查；按风险运行测试、PHPStan、迁移或命令。
- 数据库测试只能使用隔离测试环境，不连接生产数据。
- 修改结构后运行 `codegraph sync`，如实报告结果。
