# 数据核实

## 功能目标

按年度导入和核对参保数据，统一来源类别口径，匹配参保档次与救助身份，并形成税务、参保汇总结果。类别转换配置和参保档次配置属于本模块，不再作为独立“业务配置”模块维护。

## 页面入口

- `数据核实 -> 参保数据管理`：原始数据、档次匹配数据、救助身份和认定区数据的导入、编辑、导出与年份管理。
- `数据核实 -> 税务数据汇总`：按年度汇总税务口径结果。
- `数据核实 -> 参保数据汇总`：按年度汇总参保结果。
- `数据核实 -> 类别转换配置`：维护税务、医保导出和国家字典三种类别口径之间的映射。
- `数据核实 -> 参保档次配置`：维护年度代缴类别、参保档次及金额。

## 配置使用节点

### 类别转换配置

- `参保数据管理 -> 导入参保原始数据`：将来源代缴类别转换为税务代缴数据口径，再参与参保档次匹配。
- `参保数据管理 -> 导入匹配救助身份和认定区数据`：将资助身份转换为税务代缴数据口径，再判断身份是否匹配。
- 税务代缴数据口径、医保数据导出对象口径、国家字典值名称任意一列精确命中，均返回该行的税务代缴数据口径。

### 参保档次配置

- `参保数据管理 -> 导入参保原始数据`：按所选年度和转换后的代缴类别查找候选档次。
- `参保数据管理 -> 导入参保档次匹配数据`：按年度、代缴类别和档次更新匹配结果与金额。
- `参保数据汇总`：为档次、资助和金额口径提供配置依据。

配置变更只影响之后重新执行的匹配或导入，不会自动回填已保存结果。

## 主要接口与代码

- 接口：`/api/insurance-data`、`/api/category-conversions`、`/api/insurance-level-configs`、`/api/tax-summary`、`/api/insurance-summary`。
- 控制器：`InsuranceDataController`、`CategoryConversionController`、`InsuranceLevelConfigController`、`TaxSummaryController`、`InsuranceSummaryController`。
- 模型：`InsuranceData`、`CategoryConversion`、`InsuranceLevelConfig`、`InsuranceYear`。

## 业务边界

- 本模块负责参保数据核实和汇总，不负责参保台账附件3至附件7的月度流程。
- 类别额度配置仅供优抚联网结算使用，归入“联网结算”模块。
- 配置删除、覆盖导入和年度数据清理会改变后续匹配口径，执行前必须核对年度并保留原始文件。
