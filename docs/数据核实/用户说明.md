# 数据核实用户说明

完整面向用户的离线说明位于 `helps/数据核实用户操作与核对参考文档.html`。

## 推荐操作顺序

1. 在“类别转换配置”核对三种类别口径映射。
2. 在“参保档次配置”核对目标年度的代缴类别、档次和金额。
3. 在“参保数据管理”选择或创建正确年度。
4. 导入参保原始数据并查看任务进度和失败原因。
5. 按需要导入参保档次匹配数据。
6. 导入匹配救助身份和认定区数据。
7. 处理待匹配和疑似数据，抽查正常数据。
8. 导出匹配结果，再核对税务数据汇总和参保数据汇总。

## 类别转换配置

- 税务代缴数据口径是转换后的标准值。
- 医保数据导出对象口径和国家字典值名称是来源口径。
- 三列中任意一列与导入值精确相等即可命中；空格、括号和全半角差异均可能导致不匹配。
- CSV 导入时重复关系会跳过，完成后检查导入数、跳过数和错误信息。

## 参保档次配置

- 配置按年度生效，同一年度、代缴类别和档次只能有一条记录。
- 可手工维护、从已有年度生成或使用 CSV 导入。
- 年度覆盖导入会先删除该年度全部档次配置，再写入本次文件。
- 从模板生成后仍需按新年度政策逐项核对。

## 配置修改后的处理

- 修改类别转换后，重新执行受影响年度的原始数据导入或身份匹配导入。
- 修改参保档次或金额后，重新导入对应年度的档次匹配数据；需要整体重算时使用完整数据文件。
- 不要只导入无法覆盖业务关联范围的零散行，否则可能造成同一年度结果口径不一致。

## 核对重点

- 年度、来源文件和目标数据范围一致。
- 类别名称能够精确命中转换配置。
- 代缴类别、档次、资助金额和个人金额符合年度政策。
- 待匹配数量、疑似数量和汇总金额与导入文件相符。
