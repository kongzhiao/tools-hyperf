# 数据核实业务数据模型

## category_conversions

类别口径转换配置，不使用软删除。

| 字段 | 类型 | 空/默认 | 说明 | 索引 |
|---|---|---|---|---|
| `id` | bigint unsigned | 自增 | 主键 | PRIMARY |
| `tax_standard` | varchar(100) | 非空 | 税务代缴数据标准口径 | 普通索引；组合唯一键首列 |
| `medical_export_standard` | varchar(200) | 可空 | 医保数据导出对象口径 | 普通索引；组合唯一键第二列 |
| `national_dict_name` | varchar(200) | 可空 | 国家字典值名称 | 普通索引；组合唯一键第三列 |
| `created_at`,`updated_at` | timestamp | 可空 | 时间戳 | 无 |

`unique_conversion` 约束三列组合唯一；单个来源列仍可能对应多行，运行时按精确匹配取结果。

## insurance_level_configs

年度参保档次配置，不使用软删除。

| 字段 | 类型 | 空/默认 | 说明 | 索引 |
|---|---|---|---|---|
| `id` | bigint unsigned | 自增 | 主键 | PRIMARY |
| `year` | int | 非空 | 政策年度 | 普通索引；组合唯一键首列 |
| `payment_category` | varchar(100) | 非空 | 代缴类别 | 普通索引；组合唯一键第二列 |
| `level` | varchar(50) | 非空 | 参保档次 | 普通索引；组合唯一键第三列 |
| `subsidy_amount` | decimal(10,2) | 非空 | 资助代缴金额 | 无 |
| `personal_amount` | decimal(10,2) | 非空 | 个人实缴金额 | 无 |
| `effective_period` | varchar(100) | 可空 | 标准执行起止时间 | 无 |
| `payment_department` | varchar(200) | 可空 | 代缴资金支付部门 | 无 |
| `remark` | text | 可空 | 备注 | 无 |
| `created_at`,`updated_at` | timestamp | 可空 | 时间戳 | 无 |

唯一约束 `uk_year_category_level(year,payment_category,level)` 防止同一年度档次重复。

## insurance_years

参保数据管理的年度开关，包含 `year`、`description`、`is_active` 和时间戳。页面查询主要使用启用年度。

## insurance_data

参保核实主数据。保存年度、人员、身份证号、代缴类别、档次、资助身份、认定区、金额及多项匹配状态。姓名和身份证号由模型透明加解密；身份证号使用盲索引支持精确查询。完整最终字段以当前模型、敏感字段迁移和实际数据库为准。
