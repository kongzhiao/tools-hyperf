# 联网结算业务数据模型

## yf_category_quotas

优抚年度类别额度配置，不使用软删除。

| 字段 | 类型 | 空/默认 | 说明 | 索引 |
|---|---|---|---|---|
| `id` | bigint unsigned | 自增 | 主键 | PRIMARY |
| `year` | int | 非空 | 年度 | `idx_year_category` 首列 |
| `category` | varchar(100) | 非空 | 优抚类别 | `idx_year_category` 第二列 |
| `quota_amount` | decimal(12,2) | 0.00 | 每人每年补助限额 | 无 |
| `remark` | varchar(255) | 可空 | 备注 | 无 |
| `created_at`,`updated_at` | timestamp | 可空 | 时间戳 | 无 |

`idx_year_category` 是普通索引，不是数据库唯一约束；控制器和导入逻辑负责避免同年度同类别重复。

## yf_settlements

联网结算明细，不使用软删除。

| 字段组 | 主要字段 | 说明 |
|---|---|---|
| 人员 | `name`、`id_card`、`category`、`medical_category` | 姓名和身份证号由模型透明加解密，并维护盲索引用于精确查询 |
| 期间 | `period_clearing`、`period_belong`、`year`、`month` | 年月由费款所属期解析 |
| 就诊 | `visit_address`、`hospital_name`、`disease_name`、入出院和结算日期 | 导入原始信息 |
| 金额 | `total_amount`、`eligible_amount`、基金/大病/救助/个人支付等字段 | `decimal(12,2)`，默认 0 |
| 计算 | `ins_assist_total`、`yf_eligible_amount`、`annual_quota`、`used_amount`、`current_subsidy`、`remaining_amount` | 导入或重算产生 |
| 支付 | `pay_status`、`pay_at`、`remark` | -1不需支付、0待支付、1已支付 |
| 审计 | `created_at`、`updated_at` | 时间戳 |

主要索引包括身份证号/所属期、年度/月度、支付状态和创建时间；敏感字段迁移会重建身份证相关盲索引。
