# 联网结算

## 功能目标

管理优抚人员联网结算明细，按年度类别额度计算本次补助和剩余额度，并跟踪支付、重算和导出。类别额度配置属于本模块，不再作为独立“业务配置”维护。

## 页面入口

- `联网结算 -> 联网结算明细`：筛选、导入、计算、支付标记、重算、删除和导出。
- `联网结算 -> 类别额度配置`：维护年度与优抚类别对应的每人年度补助限额。

## 类别额度使用节点

- `联网结算 -> 联网结算明细 -> 导入`：根据费款所属期解析年度，按归一化后的优抚类别匹配年度额度并计算补助。
- `联网结算 -> 联网结算明细 -> 重新计算`：配置修改后按当前筛选范围重新计算年度额度、已使用、本次补助、剩余额度和支付状态。
- `联网结算 -> 联网结算明细 -> 优抚类别筛选`：页面类别选项来自已导入明细；额度配置决定计算值，不会自动改写历史类别名称。

## 主要接口与代码

- 接口：`/api/yf-settlements`、`/api/yf-category-quotas`。
- 控制器：`YfSettlementController`、`YfCategoryQuotaController`。
- 服务：`YfSettlementService`。
- 模型：`YfSettlement`、`YfCategoryQuota`。

## 业务边界

- 本模块只负责优抚联网结算，不参与参保数据的类别转换或档次匹配。
- 未命中年度类别额度时额度按 0 处理，可能形成“不需支付”。
- 配置变化不会自动更新已有结算明细，必须执行受控范围的重新计算。
