# 联网结算用户说明

完整面向用户的离线说明位于 `helps/联网结算用户操作与核对参考文档.html`。

## 推荐操作顺序

1. 在“类别额度配置”选择目标年度并核对全部优抚类别和年度额度。
2. 在“联网结算明细”下载模板并导入 CSV。
3. 从任务中心确认导入完成，查看失败原因。
4. 按年度、人员、类别和支付状态筛选核对。
5. 在支付前完成必要的重新计算。
6. 单条或批量标记支付，最后导出明细或台账归档。

## 类别额度配置

- 同一年度和优抚类别应只维护一条额度。
- 可手工新增、编辑、删除、年度克隆或 CSV 导入。
- 覆盖导入会先删除目标年度全部额度；追加导入保留已有记录并跳过重复年度类别。
- 目标年度已有数据时不能直接克隆；克隆后仍需按新年度政策逐类核对。

## 配置修改后的处理

1. 保存额度配置。
2. 回到“联网结算明细”，限定正确年度、人员或业务范围。
3. 执行“重新计算”。
4. 核对年度额度、已使用、本次补助、剩余额度和支付状态。

重新计算可能改变金额和支付状态。已支付数据也在范围内时，必须同步复核支付台账。

## 核对重点

- 费款所属期解析出的年度正确。
- 导入类别能够匹配同年度类别额度。
- 同一人员年度已使用金额没有被重复数据放大。
- 本次补助不超过符合优抚计算金额和本次可用额度。
