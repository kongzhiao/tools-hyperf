# AI开发规范

一、数据库
    1、设计数据表模型，每个字段定义好数据类型（禁止使用枚举类型，用字符串标识都可以）、长度、是否可空、默认值、字段说明等，形成数据表设计文档；
    2、每张表都需要有 id、created_at、updated_at、deleted_at 字段，主键id使用bigint UNSIGNED自增类型，其余字段mysql类型都是 timestamp NULL DEFAULT NULL；
    3、根据业务对于表数据量较大的，需要合理创建独立索引或联合索引；
    4、数据表不能使用外键、唯一索引、存储过程、视图、触发器等不利于后期维护或变更的写法；
    5、所有表都使用 innodb 引擎，utf-8mb4 编码，字符集为 utf8mb4_unicode_ci，备注好表名称，如“未救助台账-xxx表”；
    6、创建好migrations文件；

二、服务端
    1、服务端涉及到金额、数量计算的必须使用bc函数进行计算，金额保留两位小数；
    2、服务端涉及日期时间计算的，必须使用Carbon等对象进行计算；
    3、每张数据表对应一张数据模型，避免sql直接操作数据表；
    4、这次的控制器、模型等需在相应目录下创建 unrescued 目录存放；


三、前端
