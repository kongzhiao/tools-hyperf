## 功能目录

- [`系统用户管理/`](系统用户管理/)：账号、认证、角色、权限和镇街绑定。
- [`数据安全/`](数据安全/)：业务敏感字段透明加密、盲索引和旧数据升级。
- [`数据核实/`](数据核实/)：参保数据导入、类别转换、参保档次匹配和汇总核对。
- [`联网结算/`](联网结算/)：优抚结算明细、年度类别额度、补助计算和支付状态。
- [`未救助台账/`](未救助台账/)：未救助、应补应退、通知、重大疾病与筛查。
- [`参保台账/`](参保台账/)：年度配置、月度附件、台账计算、镇街复核和导出。

功能目录统一包含 `README.md`、`用户说明.md`、`业务流程图解.md`、`业务数据模型.md`、`业务变更增量.md`。
