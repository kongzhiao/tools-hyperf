业务配置用户操作与核对参考文档

更新时间：2026-07-23

业务配置决定数据核实和联网结算中的匹配口径、参保档次及优抚年度额度。应先配置、后导入业务数据；配置调整后要重新核对受影响的数据。

一、使用顺序和总原则

确认政策年度先选对年度
维护转换口径统一来源与目标名称
维护参保档次配置资助与个人金额
维护类别额度配置优抚年度限额
抽样验证再进入导入和结算
年度优先：克隆、导入、覆盖和删除年度数据前，必须再次核对目标年度。覆盖导入和删除年度配置会影响整年口径。

三、类别转换配置

入口：业务配置 -> 类别转换配置

税务代缴数据口径是目标标准，用于把医保导出口径和国家字典名称统一转换为同一业务名称。

1. 手工新增或编辑转换关系

  1. 点击 新增。
  2. 填写必填的“税务代缴数据口径”。
  3. “医保数据导出对象口径”和“国家字典值名称”至少填写一项。
  4. 保存后分别用三个口径查询，确认转换关系唯一且无多余空格。

2. 导入类别转换

  1. 下载 业务配置-类别转换.csv 模板。
  2. 按模板填写后上传 CSV；建议使用 UTF-8 编码。
  3. 重复关系会跳过，完成后核对导入数、跳过数和错误信息。
核对重点：业务名称要与来源文件完全一致。括号、空格、全半角不同都可能造成无法匹配。

四、参保档次配置

入口：业务配置 -> 参保档次配置

配置按年度生效，用于根据“代缴类别 + 金额”匹配参保档次。

1. 手工维护档次

先选择年度，再新增或编辑以下信息：代缴类别、档次、资助代缴金额、个人实缴金额、执行期、代缴部门和备注。金额应使用元，且不得为负数。

2. 从已有年度生成

  1. 点击 从模板创建，选择来源年度和目标年度。
  2. 选择“金额保留”或“金额清零”，先查看预览。
  3. 确认目标年度目前没有配置后执行。
  4. 生成后逐项核对政策变化，不要直接视为最终配置。

3. 导入年度档次

覆盖规则：页面导入会先删除所选年度的全部参保档次，再写入本次文件。务必先选对年度，并保留原配置备份。
  1. 下载 业务配置-参保档次配置.csv。
  2. 必填表头为：代缴类别、档次、资助代缴金额（元）、个人实缴金额（元）。
  3. 执行期、代缴部门和备注可选；文件不超过 128MB。
  4. 先通过页面校验并查看前 5 行预览，再确认导入。
  5. 导入后按“代缴类别 + 档次”核对条数和金额。

同一年度、同一代缴类别、同一档次只能有一条配置。删除某年度配置会删除该年度全部档次。

五、优抚人员类别额度配置

入口：业务配置 -> 优抚人员类别额度配置

该配置按年度和优抚类别维护每人每年的补助限额，直接影响联网结算的本次补助和剩余额度。

1. 手工维护额度

  1. 选择年度，点击新增。
  2. 填写优抚类别、年度额度和备注；额度不得为负数。
  3. 保存后按类别查询并核对。

2. 克隆年度额度

选择来源年度和目标年度执行年度克隆。目标年度已有数据时不能克隆；克隆后仍要逐类核对新年度政策。

3. 导入年度额度

  1. 下载 业务配置-优抚人员类别额度配置.csv。
  2. 选择目标年度和导入方式。
  3. 覆盖：先删除目标年度全部额度再导入；追加：保留已有数据，重复的“年度 + 类别”跳过。
  4. 上传不超过 128MB 的 CSV，完成后核对导入、跳过和错误数量。
名称匹配：联网结算会对类别中的空格和常见分隔符做归一化匹配，但仍建议模板、配置和业务文件统一使用同一标准名称。

六、配置变更后的处理

变更内容后续动作
类别转换关系重新执行或复核数据核实中的身份匹配结果。
参保档次及金额重新核对对应年度的档次匹配，特别是待匹配和疑似数据。
优抚类别年度额度在联网结算中按正确筛选范围执行重新计算，之后复核金额与支付状态。

七、年度配置验收清单

  • 目标年度正确，旧年度数据未被误覆盖。
  • 类别名称与来源文件一致，无多余空格或错别字。
  • 同一业务组合没有重复配置。
  • 金额单位为元，金额非负，政策执行期正确。
  • 克隆数据已按新年度政策逐条复核。
  • 至少使用一条真实样例完成匹配或结算抽查。

八、常见问题

现象处理方法
类别无法匹配核对来源值、转换值和类别额度名称，重点检查空格、括号和分隔符。
从模板创建失败目标年度已有档次配置；应先核对并决定是否删除该年度数据。
导入后旧档次不见了参保档次导入采用年度覆盖；从备份恢复并重新导入完整文件。
额度导入出现跳过追加模式下同年度同类别已存在，编辑原记录或改用经确认的完整覆盖文件。
联网结算金额仍是旧值确认额度保存成功后，在联网结算按目标范围重新计算并复核。
本文档按当前系统页面、操作按钮和业务规则整理。实际可见菜单及按钮以当前账号已分配范围为准。
