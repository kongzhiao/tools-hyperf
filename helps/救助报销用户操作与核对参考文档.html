救助报销用户操作与核对参考文档

更新时间：2026-07-23

本模块包括患者管理、就诊记录和受理记录。推荐先保证患者和就诊记录准确，再发起受理；一个受理记录可关联同一患者的多条就诊记录。

一、标准受理流程

维护患者姓名、身份证号、参保地
维护就诊记录医院、日期和费用
发起受理选择患者和未报销记录
核对银行信息银行、账号、户名
确认受理状态未申请、已受理或作废
导出台账任务中心下载归档

三、患者管理

入口：救助报销 -> 患者管理

1. 新增和编辑患者

  1. 点击 新增患者。
  2. 填写姓名、18 位身份证号和参保地区。
  3. 保存后用姓名或身份证号查询，确认不存在重复人员。
  4. 信息变化时使用编辑，不要重复新建同一身份证号患者。

2. 查看关联记录

从患者行进入详情可查看其就诊记录。患者总数和列表总数用于日常核对；患者是否完成受理应继续到受理记录中确认。

3. 删除患者

级联删除：普通删除会同时删除该患者的就诊记录；存在受理记录时需要选择级联删除，届时患者、就诊记录和受理记录都会永久删除。删除前必须先导出或截图留档，并核对身份证号。

四、就诊记录

入口：救助报销 -> 就诊记录

页面可按患者姓名或身份证号、医院、就诊类别、处理状态和入院日期查询。统计卡显示总数、未报销、已报销和已退回数量。

1. 手工新增就诊记录

  1. 点击 新增就诊记录，选择患者。
  2. 填写医院、就诊类别、处理状态和入院日期。
  3. 填写总费用、政策范围内费用，以及统筹、大额、大病、医疗救助、渝快保等金额；金额不得为负数。
  4. 按实际情况填写出院日期和结算日期，保存后查看详情核对。

2. 批量导入就诊记录

  1. 点击 导入 并下载 救助报销-就诊记录数据.csv。
  2. 至少保证姓名、身份证号和就诊医疗机构名称有效；其余字段按模板填写。
  3. 页面只接收 CSV。为保证后端能够成功处理，文件应控制在 20MB 以内。
  4. 系统按身份证号查找患者：不存在时新建患者，已存在时沿用该患者；每个有效数据行会新增一条未报销就诊记录。
  5. 任务提交后到任务中心查看结果，再返回页面核对人数和就诊记录数。
重复风险：导入不会自动替换既有就诊记录。重复提交同一文件可能新增重复就诊记录，导入前后都要按身份证号和日期抽查。

3. 删除就诊记录

删除就诊记录会同步影响关联受理：受理只关联这一条时，整个受理记录会被删除；关联多条时，该条会从受理中移除并重新计算受理金额和比例。批量删除同样适用。

五、发起受理

入口：救助报销 -> 受理记录
  1. 点击 发起受理。
  2. 按姓名或身份证号搜索并选择患者。
  3. 填写银行名称、银行账号和户名。
  4. 选择受理状态：新增时可选 未申请 或 已受理。
  5. 在就诊记录表勾选需要纳入本次受理的记录。已报销记录不能选择。
  6. 核对医院、日期、总费用及各类报销金额后提交。

提交成功后，系统把所选就诊记录汇总成一条受理记录，自动计算金额和比例，并把这些就诊记录标记为已报销，避免重复受理。

六、受理状态和编辑规则

状态含义允许的后续操作
未申请已登记但尚未确认完成受理可编辑为已受理或作废，也可删除
已受理受理已确认可查看，可编辑为作废；页面不提供删除
作废本次受理失效只能查看；关联就诊记录会恢复为未报销

编辑时患者不能更换，只能在当前已关联的就诊记录中取消选择，不能追加新的就诊记录。取消后系统重新计算金额，移出的记录恢复为未报销。

七、受理记录查询和导出

可按患者、银行名称、受理状态和户名筛选。列表显示受理编号、患者、关联就诊记录数、银行信息、总金额、政策内金额、统筹/大额/重疾金额及比例。

  1. 先设置筛选条件并点击查询。
  2. 点击详情核对银行信息、金额、比例和关联就诊记录。
  3. 点击 导出受理台账，确认当前筛选范围。
  4. 到任务中心等待完成并下载文件。

八、移动端报销受理

移动端入口：/m/medical/reimbursement

移动端提供拍照识别、选择图片和手动录入入口，共五步：OCR 识别、信息确认、报销申报、选择就诊记录、提交完成。为保证提交信息完整，建议先识别并采用银行名称、银行卡号和银行账户姓名，手动输入用于核对和补充。

  1. 拍照或选择清晰图片；可多张识别。单张图片请控制在 20MB 以内。
  2. 在识别结果中逐项采用姓名、身份证号、银行卡号、银行名称等信息；错误内容不要采用，可继续识别其他图片替换。
  3. 进入报销申报，核对并补充银行名称、银行账号、银行账户姓名。识别结果仅用于预填，必须人工复核。
  4. 系统按身份证号查询患者和就诊记录；选择至少一条非“已报销”的记录。
  5. 点击提交，记录申请编号；需要继续办理时点击 继续受理。
银行信息必须人工核对：重点比对户名、账号末四位和银行名称。OCR 结果可能因图片反光、遮挡或字体产生误识别。

九、最终核对清单

  • 患者姓名、身份证号和参保地正确且无重复。
  • 就诊记录的医院、日期和金额与来源材料一致。
  • 本次受理只选择同一患者且尚未报销的记录。
  • 银行名称、账号和户名已进行二次人工核对。
  • 受理状态符合实际办理进度。
  • 受理详情中的金额合计和比例已抽查。
  • 导出任务已完成，台账已及时下载归档。

十、常见问题

现象处理方法
患者保存提示身份证号已存在按身份证号查询现有患者并编辑，不要重复新增。
发起受理时看不到就诊记录先到就诊记录确认患者关联、处理状态和数据是否存在。
就诊记录无法勾选该记录已报销；先核对关联受理，不要重复办理。
作废后就诊记录状态变化这是正常联动，作废会把关联就诊记录恢复为未报销。
CSV 小于 128MB 仍导入失败实际处理上限为 20MB，请拆分文件后重新提交。
删除就诊记录后受理金额变化系统会移除关联并重算；应重新查看受理详情并核对。
本文档按当前系统页面、操作按钮和业务规则整理。实际可见菜单及按钮以当前账号已分配范围为准。
