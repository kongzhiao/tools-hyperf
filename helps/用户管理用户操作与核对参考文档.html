用户管理用户操作与核对参考文档

简介

用户管理用于集中维护镇街、账号、角色和操作权限，控制不同岗位可见的菜单、操作及数据范围，解决账号分配、权限管控和操作追溯问题。

更新时间：2026-07-23

一、推荐配置顺序

维护镇街先准备账号所属镇街
新增角色按岗位建立角色
分配角色权限勾选菜单和对应操作
新增用户填写账号并绑定镇街
给用户分配角色可绑定一个或多个角色
登录核验确认菜单、按钮和数据范围
最小授权原则：只分配完成岗位工作所需的角色和操作。镇街工作人员应绑定正确镇街，避免数据范围错误。

三、镇街管理

入口：用户管理 -> 镇街管理

1. 新增或编辑镇街

  1. 点击 新增，填写镇街名称；编码、排序、备注按实际需要填写。
  2. 状态选择 启用 后，该镇街可用于用户绑定；暂不使用时可设为 禁用。
  3. 保存后在列表按名称或状态查询，核对名称、编码和排序。

2. 批量导入镇街

  1. 点击 下载模板，使用 镇街管理-镇街导入.csv 填写数据。
  2. 仅上传 CSV 文件；建议保存为 UTF-8 编码。
  3. 有编码时按编码识别并更新；编码为空时按镇街名称识别并更新。
  4. 提交后到任务中心查看结果，再返回列表核对。

3. 删除镇街前核对

列表中的“账号数量”可用于检查绑定情况。镇街已有用户时不能删除，应先到用户管理把相关账号调整到其他镇街或改为全局账号。

四、角色管理

入口：用户管理 -> 角色管理

1. 添加角色

  1. 点击 新增角色。
  2. 填写必填的角色名称；描述中建议写清适用岗位和数据职责。
  3. 保存后在列表找到该角色，继续执行 分配权限。

2. 给角色分配权限

  1. 在目标角色行点击 分配权限。
  2. 可按名称、描述或路径搜索，也可展开、收起权限树。
  3. 先勾选岗位需要进入的菜单，再核对菜单下需要使用的新增、编辑、删除、导入、导出等操作。
  4. 查看页面显示的已选菜单数和操作数，确认无多选、漏选后保存。
勾选关系：权限树按父子层级联动。保存的是当前勾选结果；取消勾选后，该角色对应能力会被移除。

3. 编辑或删除角色

角色名称或职责变化时可编辑。删除角色前，先到用户管理筛选该角色并调整相关用户，避免用户下次登录后失去工作菜单。

五、用户账号管理

入口：用户管理 -> 用户管理

1. 添加用户

  1. 点击 创建用户。
  2. 填写用户名、昵称和初始密码。用户名不能与现有账号重复。
  3. 选择所属镇街；不选择时账号为全局账号。
  4. 保存后在列表按用户名或昵称查询，确认账号已出现。
字段填写说明核对重点
用户名登录时使用，必须唯一避免姓名拼音重复或共用账号
昵称页面中显示的人员或岗位名称便于操作日志追溯
密码新增时必填通过安全方式单独告知用户
所属镇街可选；为空表示全局账号镇街账号必须绑定真实所属镇街

2. 编辑用户

点击 编辑 可修改用户名、昵称和所属镇街。密码留空表示保持原密码；只有需要重置时才填写新密码。

3. 给用户绑定角色

  1. 在用户行点击 分配角色。
  2. 在“选择角色”中勾选一个或多个角色。
  3. 保存后重新打开分配窗口，核对所选角色仍然存在。
  4. 让该用户重新登录，核对菜单、按钮和数据范围。
注意：保存会以当前选择为准同步角色。取消某个角色后，该角色带来的菜单和操作也会同时失效。

4. 删除用户

确认账号不再使用后再删除。删除前建议在操作日志中核对该账号近期操作，并确认没有正在交接的任务。

六、全局账号与镇街账号

账号类型设置方式核对要点
全局账号用户的所属镇街留空通常用于区级统筹岗位，仍需按角色限制菜单和操作
镇街账号用户绑定具体镇街登录后核对只能看到本镇街职责范围内的数据

七、业务筛选选项

入口：用户管理 -> 业务筛选选项

该页面维护参保台账、未救助台账等业务页面中的下拉选项。支持按业务模块、选项类型、状态和关键词查询。

  1. 点击 新增，选择业务模块和选项类型。
  2. 填写唯一的选项值；显示名称为空时默认与选项值相同。
  3. 设置启用状态、排序、来源和备注后保存。
  4. 回到对应业务页面刷新，核对下拉项名称和顺序。

业务模块可选“未救助台账”或“参保台账”；选项类型包括医疗类别、身份类别、医药机构名称、镇街、病种名称、病种编码、参保镇街、参保原始身份、未参保原因和缴费金额。

同一业务模块、同一选项类型下，选项值不能重复。历史数据已经使用的选项，优先改为禁用，谨慎删除。

八、操作日志

入口：用户管理 -> 操作日志

操作日志只用于查询和追溯，支持按模块、动作、账号、成功或失败、关键词和时间范围筛选。

  1. 先缩小时间范围，再按账号或模块查询。
  2. 查看操作时间、账号、模块、动作、对象类型、对象编号、说明和 IP。
  3. 点击详情查看完整记录；长文本可使用复制功能。
  4. 排查失败操作时，同时记录时间、账号、模块、对象编号和失败说明。

九、用户自行修改密码

用户从右上角账号菜单打开 修改密码，依次填写原密码、新密码和确认新密码。新密码不少于 6 位，两次输入必须一致。修改成功后系统会要求重新登录。

十、新用户开通验收清单

  • 用户名唯一，昵称能够识别实际人员或岗位。
  • 镇街账号已绑定正确镇街；区级账号是否确需全局范围已确认。
  • 角色名称、描述和角色权限与岗位职责一致。
  • 用户已绑定正确角色，没有多余角色。
  • 用户重新登录后，菜单、按钮和数据范围均已现场核对。
  • 用户已修改初始密码。

十一、常见问题

现象核对顺序
用户登录后没有菜单先核对用户是否绑定角色，再核对角色是否已勾选对应菜单。
能看到菜单但没有新增或导出按钮核对角色中该菜单下的对应操作是否已勾选，保存后让用户重新登录。
镇街账号看到了错误范围的数据立即核对用户所属镇街及角色，修正后重新登录验证。
无法删除镇街该镇街仍绑定用户；先调整这些用户的所属镇街。
用户名保存失败检查用户名是否为空或与现有账号重复。
编辑用户后原密码失效确认编辑时是否填写了新密码；密码留空才表示保持不变。
