联网结算用户操作与核对参考文档

简介

联网结算用于管理优抚人员结算明细，自动计算补助金额和年度剩余额度，并跟踪支付状态，解决补助额度人工计算繁琐及支付记录难以核对的问题。

更新时间：2026-08-23

一、办理前准备

维护年度额度联网结算中先完成

导入并计算任务中心查看结果
筛选核对金额、类别、额度
标记支付单条或批量
导出归档明细、台账或打印
先配额度：导入前必须在“联网结算 - 类别额度配置”维护对应年度和类别。未匹配到额度时年度额度为 0，可能形成“不需支付”。

二、类别额度配置

入口：联网结算 -> 类别额度配置

该配置按年度和优抚类别维护每人每年的补助限额，直接用于明细导入和重新计算。

  • 联网结算明细 -> 导入：按费款所属年度和归一化类别匹配额度并计算本次补助。
  • 联网结算明细 -> 重新计算：配置修改后按当前筛选范围刷新额度、已使用、本次补助、剩余额度和支付状态。
  1. 选择年度后手工新增、编辑或删除类别额度。
  2. 也可从已有年度克隆；目标年度已有数据时不能克隆。
  3. CSV 覆盖导入会先删除目标年度全部额度；追加导入保留已有记录并跳过重复年度类别。
  4. 完成后按类别查询并至少使用一条结算明细抽查计算结果。
修改后：额度不会自动更新历史明细。必须回到联网结算明细限定正确范围执行重新计算；范围中包含已支付数据时，还要重新核对支付台账。

四、筛选和统计

入口：联网结算 -> 联网结算明细

默认按当前年度查询。基础条件包括年度、月份、支付状态和身份证号；点击 展开 后可按姓名、优抚类别、符合金额、剩余金额、入院/出院/结算日期及支付时间筛选。

顶部统计卡显示总记录数、医疗费总额、总补助金额、已支付金额及条数、待支付金额及条数。所有统计应与当前查询范围一起核对。

五、导入联网结算明细

  1. 点击 导入，下载 联网结算明细.csv。
  2. 按模板准备标准 CSV，文件不超过 128MB。
  3. 身份证号和费款所属期不能为空；系统从费款所属期解析年度和月份。
  4. 确认优抚类别名称能与该年度额度配置匹配。
  5. 上传后到任务中心查看导入成功数和失败原因，再返回页面刷新。
不去重：重复导入相同流水会新增重复记录并影响已使用额度和后续补助计算。提交前应核对文件批次；发现重复时，在支付前删除重复记录并重新计算。

六、自动计算口径

结果字段系统计算方式
医保报销 + 救助符合范围金额减去基金、大病、大额、医疗救助、倾斜救助、扶贫济困和渝快保等支出，最低为 0。
符合优抚计算“医保报销 + 救助”的 50%。
年度额度按费款所属年度和归一化后的优抚类别匹配额度配置。
已使用同一身份证号在同一年度其他记录的本次补助合计。
本次补助符合优抚计算金额与本次可用额度取较小值。
剩余额度年度额度减已使用和本次补助，最低为 0。

七、支付状态

状态适用情况可执行操作
待支付本次补助大于 0，尚未完成支付可标记为已支付，也可改回待支付
已支付已完成线下支付并登记可再次标记状态；页面禁止删除
不需支付符合计算金额为 0，或已无可用额度且本次补助为 0不能标记支付，批量操作会自动跳过

八、标记支付

1. 单条标记

  1. 先核对人员、身份证号、所属期、本次补助和剩余额度。
  2. 点击行内 标记支付。
  3. 选择已支付或待支付，填写支付时间；备注可记录支付批次或凭证信息。
  4. 保存后核对状态、支付时间和顶部统计变化。

2. 批量标记

勾选记录后点击 批量标注支付。不需支付的记录会自动跳过，可先点击“仅选可支付项”。保存前核对可处理条数、支付时间和备注。

九、重新计算

重新计算会按当前筛选条件重新计算金额、额度和支付状态。适用于年度额度配置修正或导入顺序调整后重新核算。

执行前必须确认：筛选范围、额度配置和重复数据已经核对。重新计算可能改变本次补助、剩余额度及支付状态，建议在支付标记前完成；对已支付数据重算后必须重新核对支付台账。

十、删除记录

待支付或不需支付记录可单条或批量删除，删除不可恢复。页面禁止删除已支付记录。删除某条记录后，同一人员同年度其他记录的“已使用”和“剩余额度”可能需要重新计算。

  1. 删除前记录姓名、身份证号、所属期和补助金额。
  2. 完成删除后，按该身份证号和年度筛选。
  3. 执行重新计算并核对剩余额度。

十一、导出和打印

  • 导出明细：按当前筛选条件提交异步明细任务。
  • 导出结算台账：生成面向台账归档的导出任务。
  • 打印：打印当前页已加载的数据，使用 A4 横向；打印前应确认分页和筛选范围。

导出任务完成后从任务中心下载；文件有效期为 7 天。

十二、最终核对清单

  • 所选年度和月份与费款所属期一致。
  • 优抚类别与年度额度配置匹配。
  • 没有重复流水或重复人员同次结算。
  • 本次补助不超过符合优抚计算金额和可用额度。
  • 同一人员年度“已使用 + 本次补助 + 剩余额度”与年度额度逻辑一致。
  • 只对实际完成支付的记录标记已支付，支付时间和备注可追溯。
  • 导出明细、结算台账和支付凭证已按批次归档。

十三、常见问题

现象处理方法
年度额度显示 0核对费款所属期、优抚类别及对应年度额度配置。
记录自动为不需支付核对符合计算金额是否为 0，或该人员年度额度是否已用完。
批量支付条数少于勾选数不需支付记录被自动跳过，使用“仅选可支付项”再次核对。
本次补助被后导入记录影响按身份证号和年度查看导入顺序、重复记录及已使用金额，再按正确范围重算。
删除按钮不可用该记录已支付；先确认业务上是否允许改回待支付，再按流程处理。
导入结果与文件条数不一致在任务中心查看失败原因，重点核对身份证号和费款所属期。
